How we tested it

We compared the sizes of the slugs to the amount of nematodes found on their plates.

The setup

In October 2026, every lab group in BI 221 (33 sections in total) went out and found a wild slug, either on campus or off campus. Most came from forests, yards, or around town (BI 221 Lab Manual 2026). After that, each group:

  1. Wrote down where they found the slug and what kind it was.
  2. Weighed it in grams and measured how long it was in centimeters.
  3. Put the slug on a plate so the nematodes inside could come out.
  4. Counted the nematodes under a microscope, plus how many different kinds there were.
  5. Put everything into a shared class spreadsheet.

Our conditions

This was an observational study, so we didn't give the slugs different treatments. We also split the slugs into small, medium, and large groups by weight, with the same number of slugs in each group. That made it easier to compare.

What we measured

  • Slug size, which was weight (grams) and length (centimeters)
  • Nematode abundance, meaning the total number of nematodes on the slug’s plate
  • What kind of slug it was, if it was found on or off campus, and the habitat

Cleaning up the data

The class spreadsheet had some problems, so we had to clean it up first. We took out entries that didn’t have a slug or a count. We also took out sizes that couldn’t be right, like a 283 gram garden slug (that’s heavier than a baseball). Sometimes the same slug was entered twice or shared between tables, so we only counted it once. After all that we had 148 slugs.

To see if size and nematode count were connected, we used a Spearman correlation. Basically it tells you if one number tends to go up when the other one goes up. It goes from −1 (they go in opposite directions) to 0 (no connection) to +1 (they always go up together).
